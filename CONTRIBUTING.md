# Contributing to Yamlr

We welcome contributions to Yamlr! We are committed to building the world's most reliable Kubernetes manifest healing engine.

## Core Pillars
1. **Safety-First**: All default fixes must be safe and explainable. SEMANTIC integrity is paramount.
2. **Comment Preservation**: We respect the developer's work. Never drop a comment unless explicitly required.
3. **Modularity**: Every module must follow the **Agent Modularity Protocol** (< 500 lines).

## How to Contribute
1. **Fork** the repository.
2. **Create a branch** for your feature or bugfix.
3. **Write Tests**: Every fix requires a corresponding `pytest` file in the `tests/` directory.
4. **Pass all GATES**: Trust, Comments, Determinism, Speed.
5. **Submit a PR**.

## Architectural Standards
Adhere to Clean Code principles. Ensure all logic is self-documenting and intuitive.
