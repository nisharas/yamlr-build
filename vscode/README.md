#  Yamlr: The Kubernetes Healer

Yamlr is a professional-grade Kubernetes manifest safety engine designed to stop misconfigurations before they reach production.

##  Features

- **Real-Time Forensic Analysis**: Get instant "Safety DNA" feedback as you type.
- ** One-Click Heal**: Apply professional security remediations with a single click.
- **Comment Preservation**: Unlike standard linters, Yamlr respects your formatting and comments during fixes.
- **Pro Features**: Enterprise-grade hardening (Resource Limits, NetworkPolicies, and PodSecurityStandards).

##  Getting Started

1. Zero-Config Activation: The Yamlr engine is pre-bundled and starts automatically. No manual installation is required.
2. Open any `.yaml` or `.yml` Kubernetes manifest.
3. Diagnostic errors and warnings appear immediately as inline squigglies.
4. Click Quick-Fix (or press `Ctrl+.`) to apply surgical, comment-preserving repairs.

## ⚙️ Configuration

- `yamlr.path`: Absolute path to the `yamlr` executable.
- `yamlr.harden`: Enable aggressive security hardening (Pro).
- `yamlr.enforceLimits`: Enforce resource constraints.
