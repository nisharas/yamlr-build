# yamlr licenses

**Third-Party License Attribution**

The `licenses` command displays the official list of third-party open-source libraries used within the Yamlr binary and their respective licenses.

## Usage
```bash
yamlr licenses
```

## Description
For license transparency and compliance, Yamlr includes a comprehensive manifest of all dependencies and their licensing terms (MIT, Apache 2.0, BSD, etc.).

## Output
The command prints a list of:
*   Library Name
*   Version
*   License Type
*   Full License Text (via pager)

## Examples
```bash
yamlr licenses
```

## Compliance Note
Yamlr is built with a "Zero-GPL" policy in the core engine to ensure maximum commercial flexibility and compatibility with proprietary enterprise environments.
