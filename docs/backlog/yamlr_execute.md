# yamlr execute

Headless OEM Execution API for third-party integrations `[Pro]`.

## Usage
```bash
yamlr execute [flags]
```

## Description
The `execute` command provides a high-speed, headless entry point for integrating Yamlr's remediation engine into third-party security scanners, CI/CD sidecars, or custom automation scripts. 

It is designed for **Machine-to-Machine (M2M)** communication, consuming manifests and findings reports via `stdin` or files, and outputting deterministic JSON mutations or healed content.

### Key Capabilities:
- **OEM Integration**: Use Yamlr as the "Intel Inside" remediation engine for your own security tool.
- **Remediation Ingestion**: Consume SARIF or Kyverno reports and apply fixes in a single pass.
- **Deterministic Output**: JSON-schema compliant responses for automated manifest patching.
- **Sidecar Performance**: Optimized for low-latency execution in GitOps render loops (Argo CD, Flux).

## Flags
- `--from-stdin`: Read the manifest content from standard input.
- `--manifest <path>`: Path to the manifest file if not using stdin.
- `--sarif-input <path>`: Path to a SARIF report containing findings to remediate.
- `--kyverno-input <path>`: Path to a Kyverno PolicyReport JSON to remediate.
- `--dry-run`: Output the proposed mutations as JSON instead of the healed manifest.
- `--output <format>`: Output format for the result. Options: `json` (default), `yaml`.
- `-h, --help`: Show help for the `execute` command.

## JSON Response Schema (Version 1.0)
When running with default output, `execute` returns a structured JSON object:

```json
{
  "schema_version": "1.0",
  "success": true,
  "status": "HEALED",
  "file_path": "stdin",
  "mutations": [
    {
      "target": "spec.template.spec.containers[0].securityContext",
      "description": "Injected privileged: false for security hardening",
      "rule_id": "SHD-002"
    }
  ],
  "healed_content_preview": "..."
}
```

## Examples

### Remediation via Stdin
```bash
cat deployment.yaml | yamlr execute --from-stdin --sarif-input findings.sarif
```

### Dry-Run Mutation Analysis
```bash
yamlr execute --manifest pod.yaml --harden --dry-run
```

### OEM Sidecar Integration (Argo CD)
```bash
yamlr execute --from-stdin --harden --enforce-limits --quiet
```
