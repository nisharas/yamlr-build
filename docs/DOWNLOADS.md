# Download Yamlr

## ⬇️ Download Binaries

Standalone binaries are available for Windows, Linux, and macOS. These are the **only** supported way to run Yamlr Pro and ensure 100% compatibility with our security engine.

### Package Managers (Official)
We are currently rolling out to official repositories:
*   **macOS/Linux:** `brew install yamlr/tap/yamlr`
*   **Windows:** `choco install yamlr`

### Manual Download
Download the latest executable for your platform. No Python required.

| Platform | Arch | Link |
| :--- | :--- | :--- |
| **Windows** | `amd64` | [yamlr-windows-amd64.exe](https://github.com/yamlr/yamlr/releases/latest/download/yamlr-windows-amd64.exe) |
| **Linux** | `amd64` | [yamlr-linux-amd64](https://github.com/yamlr/yamlr/releases/latest/download/yamlr-linux-amd64) |
| **macOS** | `amd64` | [yamlr-darwin-amd64](https://github.com/yamlr/yamlr/releases/latest/download/yamlr-darwin-amd64) |
| **macOS** | `arm64` | [yamlr-darwin-arm64](https://github.com/yamlr/yamlr/releases/latest/download/yamlr-darwin-arm64) |

### ⚡ Quick Start (Windows)
1.  Download `yamlr.exe`.
2.  Move it to a folder (e.g., `C:\Program Files\Yamlr`).
3.  **Add that folder to your PATH environment variable.**
4.  Open a new terminal and type:
    ```powershell
    yamlr scan .
    ```
