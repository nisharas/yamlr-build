## 3. SCHEDULE OF ASSIGNED ASSETS (SCHEDULE A)
The Intellectual Property assigned hereunder includes, without limitation:
- **Core Rust Engine (`native_core/`):** Full deterministic AST sharding, arena structurer, 21 native healers, OpenAPI v3 validator, CEL/VAP policy engine, SARIF 2.1.0 generator, eBPF/relational topology analyzer, and cryptographic signing pipeline.
- **Python SDK & Automation Plane (`src/yamlr/`):** PyO3 native extensions, CLI bridges, and backwards-compatible adapters.
- **Developer Ecosystem Integrations:**
  - VS Code Extension (`vscode/`)
  - WebAssembly Engine (`native_core/target/wasm32...`)
  - Model Context Protocol (MCP) Server
  - Language Server Protocol (LSP) Daemon
  - ArgoCD CMP Plugin (`Dockerfile.argocd-cmp`, `integrations/argocd/`)
  - GitHub Actions & Pre-commit Hooks (`actions/`, `.github/actions/`)
- **Web & API Infrastructure:** Cloudflare Workers gateway (`infra/gateway/`), documentation, marketing materials, and website (`website/`).
- **Intellectual Property Baseline:** Git commit history, architecture blueprints, feature scorecards, and benchmark suites.
