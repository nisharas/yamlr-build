# yamlr pulse
[STRATEGIC] Founder Intelligence: View aggregate rule efficacy and ecosystem ROI.

## Usage
```bash
yamlr pulse
```

## Description
Provides high-fidelity strategic telemetry on which rules are triggering most across the ecosystem and the total financial-equivalent value reclaimed by the Yamlr engine.

## Flags
* `--output`: Output format (`text` or `json`).

### 🛡 Universal Expert Flags
Available across primary commands:

*   **`--timing`**: [PERFORMANCE] Output surgical execution timing breakdown.
*   **`--timing-file <FILE>`**: [PERFORMANCE] Save performance profiling data to a JSON file.
*   **`--verbose`**: Full audit logs and engine stages.
*   `-q`, `--quiet`: Minimal output mode (exit codes only).
